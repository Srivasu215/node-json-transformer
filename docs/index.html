How Node Transformer Works

A single-pass recursive engine that separates data from output structure. It takes any raw JSON or XML-derived payload, resolves dotted paths, renames keys, and builds clean schema contracts declaratively.

The Two-Document Model
The core architectural concept behind node-json-transformer.

Instead of writing imperative transformation logic (loops, nested checks, property assignments), Node Transformer evaluates two documents: the Source Data and the Transformation Recipe. The recipe describes the exact output shape you want to construct.

Document 1
Source JSON
Raw input payload with enterprise, legacy, or XML-like keys (e.g. dotted keys, arbitrary nesting).
➔
Document 2
Transformation Recipe
Declarative contract. Output keys belong to the recipe; values specify source path instructions.
➔
Result
Transformed Output
Clean, normalized contract ready for APIs, databases, or UI table visualization.
💡 Key Principle: Output keys belong entirely to the transformation recipe. The source is only queried when a value needs to be retrieved.
⚙️
Execution Pipeline & Traversal Engine
How the recursive engine processes transformations in a single pass.
01
Entry & Context
transform(source, recipe) initializes traversal with root references, configuration, and source payload.
02
Dispatch Decision
The dispatcher identifies whether the current recipe node represents an item (object), a list (array), or a flat selection.
03
Path Resolution
Handles nested dot-notation ("customer.address.city") and legacy dotted XML keys without throwing undefined errors.
04
Recursive Composition
The same rules repeat seamlessly: Object ➔ Array ➔ Object ➔ Array without needing custom loop logic.

See It in Action
A side-by-side demonstration of input, recipe, and resulting output.
📄 1. Raw Source Data 
{
  "ORDER_HEADER": {
    "VOUCHER_NO": "INV-2026-09",
    "PARTY_NAME": "Keshav Enterprises"
  },
  "ITEM_LIST": [
    {
      "ITEM_NAME": "Widget Alpha",
      "QTY": 10,
      "RATE": 150
    }
  ]
}
📜 2. Transformation Recipe 
{
  "item": {
    "invoiceNumber": "ORDER_HEADER.VOUCHER_NO",
    "client": "ORDER_HEADER.PARTY_NAME",
    "products": [
      {
        "list": "ITEM_LIST",
        "item": {
          "product": "ITEM_NAME",
          "quantity": "QTY",
          "price": "RATE"
        }
      }
    ]
  }
}
✨ 3. Clean Output Contract 
{
  "invoiceNumber": "INV-2026-09",
  "client": "Keshav Enterprises",
  "products": [
    {
      "product": "Widget Alpha",
      "quantity": 10,
      "price": 150
    }
  ]
}
