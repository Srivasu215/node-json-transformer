How to Use node-json-transformer via CDN

Unified declarative transformation engine. Combines field selection, property renaming, and contract schema mapping in a single pass. Designed especially for JSON derived from XML/Tally structures with dot-notated keys.

🔮 node-json-transformer
Unified Engine
Mental Model: Source JSON contains data, Transformation JSON describes output. Selected, renamed, and reshaped simultaneously.
node-json-transformer — Primary Usage Pattern 
const { transform } = require("node-json-transformer");

const result = transform(data, {
  item: {
    customer_name: "CUSTOMER_NAME",
    transaction_date: "TRANSACTION_DATE"
  }
});

1. Browser CDN Script Tag (No Node.js Required)
Load node-json-transformer directly in any client-side browser HTML file via jsDelivr CDN.

Import node-json-transformer as an ES module directly from the official repository CDN:

HTML — ES Module CDN Import 
<!-- Import node-json-transformer via jsDelivr CDN -->
<script type="module">
  import { transform } from "https://cdn.jsdelivr.net/gh/keshavsoft/node-json-transformer@main/src/index.js";

  // 1. Raw source data (e.g. from API or Tally/XML export)
  const data = {
    CUSTOMER_NAME: "Keshav",
    TRANSACTION_DATE: "2026-09-30"
  };

  // 2. Declarative contract specification
  const result = transform(data, {
    item: {
      customer_name: "CUSTOMER_NAME",
      transaction_date: "TRANSACTION_DATE"
    }
  });

  console.log("Transformed Contract:", result);
  // Output: { customer_name: "Keshav", transaction_date: "2026-09-30" }
</script>
