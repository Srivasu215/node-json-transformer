        💡 Architectural Story & Analysis
      

      

        

          In traditional procedural programming, reshaping a flat object into a nested object requires creating intermediate variables, null checks, and manual property assignments:
        

        
    
          
  • Source Data: Has three flat fields at the root level: firstName, city, and age.
    • 
          
  • Guide Blueprint: Declares an output property named person with its own nested item block containing name and location, while keeping age at the root level.
    • 
          
  • Recursive Traversal: The engine traverses into person.item, evaluates name = firstName and location = city, and constructs the nested output object without altering the root source.
    • 
          
  • Whitelisting Principle: Output keys belong 100% to the Guide. The source is only queried when a value needs to be retrieved.
